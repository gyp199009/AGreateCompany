# 01 · 产品方向

本文件回答三个问题：**机会在哪里**、**我们选哪几个做**、**第一个产品具体长什么样**。

标注约定：`【判断】`= 我们的推理，可被推翻；`【待验证】`= 必须用实验或访谈换来的事实。

---

## 1. 机会地图：六个候选方向

筛选框架：任何方向必须先过**三道闸**，再谈分数。

1. **社会价值闸**：如果做成了，它是否改变了一群人的能力边界（而不只是省了他们一点时间）？
2. **技术匹配闸**：能否用"证据 + 推理 + 工具"这套底座解决，而不是需要全新的硬件或实验室？
3. **可持续闸**：是否存在一个"愿意为自己付费、且不是靠补贴"的买家？

### 1.1 评分（1–5，5 最好；"合规"与"壁垒"已做正向归一）

| 方向 | 社会价值 | 商业空间 | 技术可行 | 数据可得 | 合规风险低 | 壁垒易建 | 时机 | 与底座协同 | 合计 |
|---|---|---|---|---|---|---|---|---|---|
| **A. 科研加速器**（面向研究者，证据→假设→实验设计） | 5 | 4 | 4 | 4 | 4 | 4 | 4 | 5 | **34** |
| **B. 产业研发助手**（材料 / 化工 / 生物医药 R&D） | 5 | 4 | 4 | 3 | 4 | 4 | 3 | 5 | **32** |
| C. 个性化学习教练 | 5 | 4 | 4 | 4 | 4 | 2 | 4 | 2 | 29 |
| D. 无障碍与认知辅助 | 4 | 2 | 4 | 3 | 4 | 3 | 3 | 3 | 26 |
| E. 公共服务文档 / 合规助手 | 3 | 3 | 4 | 3 | 3 | 3 | 3 | 3 | 25 |
| F. 个人健康数据 OS | 5 | 5 | 2 | 2 | 2 | 3 | 3 | 2 | 24 |

### 1.2 取舍理由（为什么不是别的）

- **C（教育）被排除为主攻**：社会价值极高，但壁垒薄、获客成本被大厂与内容巨头挤压，且与我们的技术底座几乎不产生复利。**结论：不作为主攻方向；但如果出现"教育渠道"型合作（例如研究生方法论训练），可以用同一底座低成本接入。**
- **F（健康 OS）被排除**：需要穿戴设备、医疗责任、数据合规三重门槛，24 个月内不可能同时跨过。**结论：观察，等监管与硬件生态成熟。**
- **D / E 作为第三年的公益/品牌线**，因为它们能强化"意义"叙事，但不能承担现金流。
- **A 是核心，B 是收入引擎**：两者共用同一套证据引擎，只是数据源与交付形态不同（A 偏公开文献，B 偏专利 + 内部文档 + 实验数据）。这是本文件最重要的结构判断：**不要做两个产品，要做一套底座 + 两个包装。**

## 2. 产品组合（Portfolio）

```
                    ┌──────────────────────────────┐
   公共品 / 品牌层   │  P3 开放证据图谱（Open Evidence Graph）│
                    │     免费 API + 公益计划             │
                    └───────────────▲──────────────┘
                                    │ 数据回流
        ┌───────────────────────────┴───────────────────────────┐
        │         P0 证据引擎（Evidence Engine）—— 单一底座          │
        │  摄取 · 规范化 · 实体链接 · 证据图 · 断言验证 · 评测        │
        └───────────▲───────────────────────────▲───────────────┘
                    │                           │
        ┌───────────┴──────────┐    ┌───────────┴────────────────┐
        │ P1 学术版             │    │ P2 产业版                   │
        │ Hypothesis Workbench │    │ R&D Intelligence           │
        │ 目标：研究者生产力      │    │ 目标：企业研发决策与专利风险    │
        └──────────────────────┘    └────────────────────────────┘
```

一个底座四个出口，意味着：**每多一个出口，边际成本远低于从零做第二个产品。** 这是我们的资本效率论证。

## 3. P0 · 证据引擎（Evidence Engine）—— 内部平台

**一句话**：把"一句话"变成"一张带出处的证据卡"，并诚实地说出这张卡有多可信。

**它是什么**

- 输入：一个断言 / 一个问题 / 一篇文档 / 一份实验记录。
- 输出：结构化的 **Claim Card**——
  - 断言被拆成的最小命题（claim decomposition）；
  - 每个命题的**支持 / 反驳 / 无结论**证据列表（含文献段落原文、DOI/PMID、样本量、研究类型、年份）；
  - 一致性判断（不同研究之间是否冲突，冲突在哪一层：人群 / 剂量 / 终点 / 方法）；
  - 置信等级 + **它为什么是这个等级**（可解释的评级理由，不是黑箱分数）；
  - 明确的"我们还不知道什么"（knowledge gaps）。

**为什么它是底座而不是功能**：P1 的工作台、P2 的尽调报告、P3 的开放 API，本质都是"对 Claim Card 的不同编排与呈现"。把它做厚，才有复利。

**技术边界（V1 明确不做）**：不做图像/图表内数值抽取（V2 再做）；不做跨语言（除中英）；不做多模态实验视频。

## 4. P1 · 学术版 Hypothesis Workbench

### 4.1 用户与场景

| 画像 | 真实任务（JTBD） | 现在的做法 | 我们的介入点 |
|---|---|---|---|
| **PI / 课题组长** | 判断"这个方向值不值得投一个博士生三年" | 读综述、问同行、凭直觉 | 用证据图给出"该领域已解决/未解决的清单 + 冲突点" |
| **博后 / 高年级博士** | 写立项书、找选题切口、做文献综述 | Zotero + 关键词检索 + 手工 Excel | 自动生成"证据矩阵"与"可检验的空白点" |
| **跨领域进入者**（如做 AI 的人进生物） | 快速建立领域地图，不犯低级错误 | 读教科书 + 问人 | 领域本体导航 + 概念消歧 + 经典/前沿分层 |

**最锋利的那一刀**：不是"帮你读得更快"，而是**"在你要投入三个月之前，告诉你这个假设已经被别人证伪过，或者从未有人真正测过。"**

### 4.2 MVP 范围（0–9 个月）

**In**

1. 项目空间（project workspace）：一个课题 = 一组问题 + 一批文献 + 一张证据图。
2. 文献摄取：开放获取论文全自动（PDF 结构解析 + 段落级引用锚定）；付费文献走用户上传（合规见 §7）。
3. **断言级证据矩阵**：任意两个断言可做"支持/反对比对"，导出为表格。
4. **冲突检测与失败结果提示**：显式标注"阴性结果 / 样本量不足 / 仅在动物模型"。
5. **实验方案草案**：给出可检验的设计骨架（变量、对照、样本量提示、常见陷阱），并逐条标注依据来源。
6. **证据卡导出**：Markdown / DOCX / BibTeX，引用与原文逐句对齐（点击即定位到 PDF 段落）。
7. 团队协作的最小集：评论、指派、版本对比。

**Out（明确不做，写进销售话术）**

- 不写论文正文、不生成投稿信、不做同行评审意见。
- 不执行实验、不代做统计分析结论（只给方法建议与检查清单）。
- 不做多组学数据处理管线（通过集成，不自建）。
- 不做全学科覆盖：V1 只支持 **1 个主领域 + 1 个验证领域**（选择见 `03-delivery-plan.md`）。

### 4.3 差异化（为什么不是"又一个文献工具"）

| 别人在做 | 我们做 |
|---|---|
| 检索 + 摘要 + 问答 | 断言级拆解 + 逐条证据评级 |
| 单篇理解 | 跨文献**冲突**与**一致性**建模 |
| 引用作为格式 | 引用作为**可点击定位的锚点**（段落级 offset） |
| 一个通用分数 | 可解释的置信等级 + 弃权 |
| 用户自己判断可信度 | 对外公开评测 + 失败案例库 |

### 4.4 定价假设【待验证】

- **Free**：每月 30 次证据卡，公开文献，单用户。
- **Researcher**：$25–35 / 月，无限证据卡，导出，PDF 上传。
- **Lab**：$99 / seat / 年（≥5 seats），共享项目空间、审计日志、机构 SSO。
- **公益**：低资源地区 / 非营利机构免费（配额制），作为 P3 的一部分。

> 定价的目标不是榨取，而是筛出"真的在用"的用户。若转化率 < 3%，先怀疑产品，不要怀疑价格。

### 4.5 成功判据（上线后 12 个月，与 `03` 的 Q4 对齐）

| 指标 | 目标 |
|---|---|
| 周活跃研究者（WAU，定义：每周产生 ≥3 张证据卡） | 300+ |
| 采纳率（生成的假设中被标记"值得验证"的比例） | ≥ 25% |
| 专家抽检：断言-证据对齐正确率 | ≥ 92% |
| 从"提出问题"到"得到可导出证据矩阵" | ≤ 20 分钟 |
| 付费转化（活跃用户中） | ≥ 5% |

## 5. P2 · 产业版 R&D Intelligence（收入引擎）

**一句话**：让企业研发团队在立项、避专利、选路线这三件事上，少做三个月无用功。

**客户**：材料、化工、生物医药、新能源的中型研发组织（研发 50–500 人）。不卖给最大的一家，先卖给"痛但还灵活"的那一档。

**三个可售场景（按可交付性排序）**

1. **立项尽调包**：给定技术目标，输出"已有路线图谱 + 主要玩家 + 专利雷区 + 未被覆盖的空白 + 建议的 3 条可测路线"。按项目收费，最容易验证价值。
2. **专利与文献风险体检**：对客户自己的技术方案，逐条比对在先文献/专利，输出风险等级与规避建议（明确声明非法律意见）。
3. **内部知识缝合**：接入客户的 ELN / 报告 / 邮件 / 测试数据，让"我们三年前是不是试过这个"变成一次查询。

**交付形态**：私有化 / VPC 部署优先（这是企业采购的硬门槛），SaaS 次要。

**定价假设【待验证】**：立项尽调包 $15k–40k / 项目；年度平台许可 $80k–250k（含私有部署与 SSO）；不做按 token 计费（客户无法预算）。

**成功判据（18 个月）**：3–5 个付费设计伙伴 → 2 个续约 → 净收入留存 > 110%；单项目交付人力 ≤ 5 人日。

## 6. P3 · 公共品：开放证据图谱 + 公益计划

**为什么一个商业公司要做这个**

- **道义上**：使命是对社会的；一个只服务付费用户的产品，无法声称自己在加速"人类的发现"。
- **战略上**：公开图谱与公开评测会成为行业引用标准（citation standard），这是比专利更稳的护城河，也是最好的招聘广告和信任凭证。
- **数据上**：公益用户与开放 API 的调用会暴露系统性弱点，成为最好的评测数据来源。

**形态（第三年启动，第二年做技术准备）**

- 开放 **Claim Card API**（免费额度 + 学术机构白名单），附完整的方法学说明。
- 定期发布《证据质量年报》：哪些领域的证据最脆弱、哪些"常识"其实证据不足。
- 与大学 / 非营利合作，为低资源地区研究者提供免费席位。

**约束（防止它拖垮公司）**：人力投入 ≤ 1 人当量；数据许可必须允许再分发；不以"公益"名义承诺 SLA。

## 7. 合规与信任的产品化（不是法务附录）

| 议题 | 产品化做法 |
|---|---|
| **文献版权** | 默认只用开放获取 + 客户自带 + 已授权语料；不建立"影子图书馆"；对每篇文献记录许可类型并在导出时保留 |
| **科研诚信** | 输出永不伪装成"作者原话"；导出的文档强制携带 AI 使用声明模板；不提供"降重/规避查重"能力 |
| **幻觉** | 断言级来源校验 + 弃权 UI + 置信等级可解释；无来源断言在 UI 上使用不同视觉语言 |
| **生物安全（dual-use）** | 对涉及病原体增强、毒素合成等请求做硬拦截与客户尽调（KYC）；见 `04` |
| **数据主权** | EU / US 区域化存储；客户数据默认不进入共享训练集；可签署 DPA；退出即删除并提供删除证明 |

> 这些条款会让我们在增长上慢一点。这是刻意的：**在一个"信任就是产品"的市场里，合规不是成本，是营销。**

## 8. 方向层面的待验证假设（前三条最致命）

| # | 假设 | 验证方式 | 判定标准 | 时间盒 |
|---|---|---|---|---|
| H1 | 研究者会为"证据质量"付费，而不只是为"更快"付费 | 20 位深访 + 假门测试（定价页 A/B） | ≥ 6 人愿以 ≥$25/月预付 | 6 周 |
| H2 | 断言级证据对齐能做到专家可接受 | 200 条断言盲评（3 位领域专家） | 正确率 ≥ 90%，且"严重错误" ≤ 2% | 10 周 |
| H3 | 单领域开放语料足以覆盖核心问题 | 对 50 个真实问题的召回实测 | 关键证据召回 ≥ 80% | 4 周 |
| H4 | 企业愿意为"立项尽调"单独付费 | 5 家企业报价测试 | ≥ 2 家签付费 PoC | 12 周 |
| H5 | 冲突检测优于专家直觉 | 与 2 位专家对 50 组冲突的盲比 | 不劣于专家（可接受"互补"） | 16 周 |

**任何一条失败，都在 `03` 的季度评审里触发一次明确的"继续 / 转向 / 停止"决定，而不是无限期拖延。**
