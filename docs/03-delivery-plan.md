# 03 · 交付计划（0–36 个月）

以季度为单位，每个季度只有一个**主题**。主题多了，就等于没有主题。

> 若某一季度的主题没完成，下一季度不得启动新主题，只能补课（"不许叠加新承诺"规则）。

## 2. 季度细节

### Q1 · 选领域 + 打通链路

- **决策**：主领域从 2 个候选中用数据选（**候选：神经退行性疾病 / 电化学储能材料**）。选择依据只有三条：开放语料覆盖率（H3）、专家的可获得性、以及有没有 3 家愿意每周来开会的设计伙伴。
- **交付**：单机管线；5k 篇全文；证据图 v0；Claim Card v0；Run Ledger；内部评测 harness。
- **指标**：断言对齐正确率 ≥ 90%；单卡成本 ≤ $1.5；P95 < 90s。
- **风险**：PDF 解析质量拖垮一切。缓解：第 2 周就建 200 篇"解析地狱集"，把解析当独立产品打磨。

### Q2 · 设计伙伴验证

- **交付**：证据矩阵导出（DOCX/XLSX）；冲突检测 v0；10 家伙伴每周使用；定价假门测试。
- **决策点**：**H1（愿为证据质量付费）与 H3（语料足够）在此判定。** 任一失败 → 触发方向重评（见 §5）。
- **指标**：伙伴周活 ≥ 70%；"值得验证"采纳率 ≥ 20%。

### Q3 · 产品化

- **交付**：多租户 SaaS、RBAC、SSO、审计日志、CI 评测门禁、生物安全分类器、语义缓存。
- **指标**：可用性 99.5%；无来源断言率 < 2%；检索召回 ≥ 82%。
- **纪律**：本季度**不接定制需求**，一律进 backlog。

### Q4 · 付费验证

- **交付**：学术版 GA（Free/Researcher/Lab 三档）；SOC 2 Type I 启动；对外发布方法学文档。
- **指标**：付费 ≥ 60 人；活跃用户付费转化 ≥ 5%；月流失 < 5%；300 WAU。
- **决策点**：**H2（专家可接受度）复核。** 若驳回率 > 8%，暂停增长投入，先修判定质量。

### Q5–Q6 · 产业版

- **交付**：立项尽调包（可重复交付的模板化产出）；私有化 Helm 包；客户内部数据连接器（先做 2 个，不做 10 个）。
- **指标**：≥ 2 个付费 PoC；单项目交付 ≤ 5 人日；续约 ≥ 1。
- **纪律**：企业定制以"配置"实现，不以"分支"实现。任何客户专属代码分支 = 技术债，需 CTO 签字。

### Q7 · 信任资产

- **交付**：SOC 2 Type II；公开评测报告 #1（含失败案例）；主动学习闭环（用户反馈 → 标注 → 重训 → 评测）。
- **指标**：判定 F1 ≥ 0.88；ECE ≤ 0.06；单卡成本 ≤ $0.25。

### Q8 · 平台化

- **交付**：开放 Claim Card API 公测；第 3 个领域；与一家自动化实验平台 / CRO 的集成 PoC。
- **指标**：外部开发者 ≥ 30；API 月调用 ≥ 100k；第 3 个领域达成 80% 的领域一质量水位。

## 4. 资源与预算（12 个月，量级估算）

| 项 | 占比 | 说明 |
|---|---|---|
| 人力 | 60–65% | 12–14 人（Phase 1 末） |
| 推理与存储 | 15–18% | 随用户增长，但单位成本必须逐季下降 |
| 数据许可与合作 | 8% | 专利数据、部分商业文献索引、领域本体维护 |
| 合规与法务 | 5% | SOC 2、DPA、生物安全顾问、版权意见 |
| 工具与云基础设施 | 5% | 观测、CI、安全扫描、协作 |
| 缓冲 | 5% | 不可动用，只用于事故与合规突发 |

> **纪律**：推理成本增速若连续两个月超过收入增速，冻结一切非必要实验，先做成本工程。这条规则写在预算里，而不是等到现金流紧张时才讨论。

## 5. Kill Review（每季度一次的显式决定）

每个方向必须回答四个问题，答不上来就停止：

1. 过去 90 天，NSM 是否朝正确方向变化？如果没变，是产品问题还是市场问题？
2. 有没有至少 3 个用户**在没有我们催促的情况下**主动回来用？
3. 我们的质量指标是否在**不变差**的前提下扩大覆盖？如果靠降标准换增长，立即停。
4. 如果今天从零开始，我们还会选这个方向吗？

**触发转向的三个硬条件（任一成立即启动重评）**

- 连续两个季度 NSM 无增长，且质量指标已达标（说明不是质量问题，是需求问题）。
- 单位采纳成本连续两季上升且无法解释。
- 出现一个让"证据链"变得不重要的技术变化（见 `02` §12）。

**停止的原则**：停止一个方向时，必须保留其**数据资产与评测集**——那是我们投入产出比最高的部分。

## 6. 三个季度的"不做清单"（防扩散）

| 时间 | 明确不做 |
|---|---|
| Q1–Q2 | 不做多领域、不做移动端、不做 API、不做私有化、不做企业销售 |
| Q3–Q4 | 不做自动化实验、不做图像抽取、不做非中英文、不做市场投放 |
| Q5–Q6 | 不做自研基础模型、不做硬件、不做临床诊断、不做行业 marketplace |

> 这份清单的作用是：当有人问"为什么不做 X"，回答不是"没资源"，而是"不在这一季的主题里"。前者是软弱，后者是纪律。
